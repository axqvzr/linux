# Screenshot and screen recording in fedora or ubuntu (Default)

- Crtl + Shift + Alt + R &rarr; Start/Stop recording.
- To hide pannel or other use `just perfection` extension.

- Third party app: `GPU Screen Recorder` from dec05eba.

# Adding Shortcut keys for application
For this we taking terminal.
- Setting &rarr; Keyboard &rarr; View & Customize Shortcuts &rarr; Custom shortcuts &rarr; Add Shortcuts
    - Name: Give any relevant name you like
    - Command: Actual name of the app. To know the name
        - Google search or AI
        - Right click &rarr; app details &rarr; find name
    - Shortcut: Press all keys at once
    - Command: `/usr/bin/ptyxis -- new-window` name of the app, or get help from AI.
